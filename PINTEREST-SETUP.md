## Deployment

Push to a GitHub repo and enable Pages:

```bash
git init
git add .
git commit -m "OpenClaw Setup Service landing page"
git remote add origin https://github.com/Porfirio-Piero/openclaw-setup-service.git
git push -u origin main
```

Then enable GitHub Pages from repo Settings > Pages > main branch.

Live URL will be: `https://porfirio-piero.github.io/openclaw-setup-service`
