# WaitlistPro

A complete waitlist landing page builder with referral tracking, analytics, and 5 beautiful templates.

## Features

- **5 Templates**: SaaS, App, Course, Newsletter, Physical Product
- **Email Capture**: With optional double opt-in verification
- **Referral System**: Unique codes, tracking, leaderboards
- **Analytics Dashboard**: View signups, export CSV, track conversions
- **Custom Branding**: Colors, fonts, logos
- **Free & Pro Plans**: Free tier with 1 waitlist/100 signups, Pro at $15/mo unlimited

## Quick Start

```bash
npm install
npm run dev
```

## Deployment

1. Push to GitHub
2. Connect to Vercel
3. Add `BLOB_READ_WRITE_TOKEN` environment variable
4. Deploy!

## Environment Variables

See `.env.example` for required variables.
