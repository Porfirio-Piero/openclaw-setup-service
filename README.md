---

## Quick Start

1. Open `GUMROAD-LISTING.md` and create the product at https://gumroad.com/
2. Upload `hero.png` as the cover image.
3. Set price to $50.
4. Publish the product.
5. Follow `PINTEREST-SETUP.md` to create a business profile and pin the product.
6. Deploy `index.html` to GitHub Pages (or Vercel/Netlify) for a branded landing page.
